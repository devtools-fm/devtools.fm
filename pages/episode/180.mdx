This week we're joined by Tarun Sachdeva, founder of Traces and previously head of product at Wattpad.
Traces gives coding agent sessions a home: a CLI that collects sessions from Claude Code, Codex and other harnesses, and traces.com, where you can share them like pushing code to GitHub and link them to the commits and pull requests they produced.
We talk about why agent sessions are decision data worth keeping, privacy and sharing defaults, rethinking code review as its own agent session, Surfaces for visualizing tokens, skills and security risks, and how teams can use trace data to learn without it feeling like surveillance.
